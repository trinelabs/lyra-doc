# Lyra — Documentation

Public documentation for **Lyra**, the self-contained Agentic SOC
platform — a full SIEM, a visual SOAR engine, and an autonomous AI
analyst team in one deployable product.

## Contents

- **[User guide](USER_GUIDE.md)** — using Lyra from the web UI: logging
  in, the navigation map, adding a log source, searching, dashboards,
  alert triage, connecting an AI model, and the AI analyst team. Written
  for analysts; no terminal required.

> Flowcharts in the guide render as diagrams when viewed on GitHub.
